# MAMA - Maternal Health Companion for Ghana 🤱

**Your trusted AI-powered companion for a healthy pregnancy journey in Ghana**

## 🌟 About MAMA

MAMA is a comprehensive maternal health application designed specifically for expectant mothers in Ghana. Our AI-powered platform provides personalized pregnancy guidance, health tracking, and 24/7 support in local languages including Twi and Akan.

## ✨ Key Features

- **🤖 AI Health Assistant** - Get instant answers to pregnancy questions anytime
- **📱 Pregnancy Tracker** - Monitor your baby's development week by week
- **🏥 Clinic Locator** - Find nearby healthcare facilities and specialists
- **⏰ Smart Reminders** - Never miss appointments or medication schedules
- **🗣️ Multilingual Support** - Available in English, Twi, and other local languages
- **👥 Community Support** - Connect with other expectant mothers
- **🚨 Emergency Features** - Quick access to emergency contacts and services
- **📚 Educational Resources** - Evidence-based pregnancy and childcare information

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/mama-health-ghana/mama-app.git

# Navigate to project directory
cd mama-app

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
# Create production build
npm run build

# Preview production build
npm run preview
```

## 🛠️ Technology Stack

- **Frontend**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui + Radix UI
- **State Management**: React Query
- **Routing**: React Router DOM
- **Icons**: Lucide React
- **Notifications**: Sonner
