# Contributing to MAMA - Maternal Health Companion

Thank you for your interest in contributing to MAMA! We welcome contributions from developers, healthcare professionals, and community members who share our mission of improving maternal health outcomes in Ghana.

## 🤝 How to Contribute

### Reporting Issues
- Use GitHub Issues to report bugs or suggest features
- Provide detailed descriptions and steps to reproduce
- Include screenshots or error messages when applicable

### Code Contributions
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Add tests if applicable
5. Commit your changes (`git commit -m 'Add amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

### Development Setup
```bash
# Clone your fork
git clone https://github.com/your-username/mama-app.git

# Install dependencies
npm install

# Start development server
npm run dev
```

## 📋 Guidelines

### Code Style
- Use TypeScript for type safety
- Follow existing code formatting
- Use meaningful variable and function names
- Add comments for complex logic

### Commit Messages
- Use clear, descriptive commit messages
- Start with a verb (Add, Fix, Update, Remove)
- Keep the first line under 50 characters

### Pull Request Process
1. Update documentation if needed
2. Ensure all tests pass
3. Request review from maintainers
4. Address feedback promptly

## 🏥 Healthcare Content Guidelines

When contributing health-related content:
- Ensure information is evidence-based
- Cite reputable medical sources
- Consider cultural context for Ghana
- Avoid providing specific medical advice
- Encourage users to consult healthcare providers

## 🌍 Localization

Help us make MAMA accessible in local languages:
- Translate UI text to Twi, Ga, Ewe, or other Ghanaian languages
- Ensure cultural appropriateness
- Test translations with native speakers

## 🐛 Bug Reports

Include:
- Device/browser information
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable

## 💡 Feature Requests

Consider:
- How it benefits expectant mothers in Ghana
- Technical feasibility
- User experience impact
- Alignment with project goals

## 📞 Contact

- Email: contribute@mama-health-ghana.com
- GitHub Discussions: Use for questions and ideas
- Issues: For bugs and feature requests

## 🙏 Recognition

Contributors will be acknowledged in our README and release notes. Thank you for helping make pregnancy safer and healthier for mothers in Ghana!
